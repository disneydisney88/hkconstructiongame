瀏覽器 3D 開放世界小遊戲 — **真實香港地圖**(九龍灣 / 啟德 / 觀塘牛頭角,
OpenStreetMap 數據:1,046 棟樓、4,306 條道路、32 個真實地盤區),扮演一個
戴安全帽連帽帶、反光衣背寫「香港建築」、著安全鞋嘅地盤工人,避開白帽
安全主任留難,做齊開工任務,收工去茶餐廳!

## 🚀 點樣開始玩

**方法(最簡單):** 雙擊 `開game.bat` — 佢會自動起本地 server 同打開瀏覽器。

**手動方法:**
```
cd hk-gta
python -m http.server 8123
# 瀏覽器打開 http://localhost:8123/
```
> ⚠️ 因為用咗 ES module,直接雙擊 index.html(file://)係開唔到㗎,一定要行 localhost。
> 需要上網(Three.js 由 CDN 載入)。

## 📋 任務流程(開工一日)

1. **① 新仔入職** — 去地盤閘口搵老陳 → 上安全訓練堂(5 題粵語測驗,答錯重讀)
   → 訓練室由白帽安全督導員量血壓(節奏小遊戲,要中 3 次;跑完步去量會爆錶 FAIL!)
   → 領齊 PPE → 閘口按 E 開啟入場核對 → 嘟卡入場
2. **② 送外賣** — 攞飯盒送畀 5 個工友
3. **③ 搬磚上斗車** — 扛 4 籠磚(扛嘢行慢咗)
4. **④ 天秤危機** — 喺吊運範圍入面執工具箱(參考勞工處吊運意外)
5. **⑤ 環保斗車** — 車尾蓋帆布 → 過洗車槽 → 出閘送廢料(未蓋帆布 $50,000 / 車轆未洗 $30,000!)
6. **⑥ 收工** — 去茶餐廳飲凍檸茶,結算人工(零警告有 安全獎 +$500!)

## ⚠️ 遊戲機制

- **白帽安全主任**:到處巡邏,你有「⚠ 安全警示」星就會追捕你;被捉 = 警告,
  3 個警告 = 強制安全再培訓(人工 -$500)
- **行政費罰款**(參考真實地盤扣罰清單):撞跌水馬(移走安全圍欄 $2,000)、
  高空擲物($2,000)、塵埃管制($20,000)、未登記入場($3,000)、偷開斗車…
- **勞工處危險源**:天秤吊墜物、泥頭車倒車(聽到「比比比」要讓開)、
  挖掘機機臂、泥坑、跌落海
- **工傷系統**:血歸零 = 入聯合醫院(真實 POI),人工 -$300
- **安全獎**:連續 3 分鐘零警告 +$50;全日零警告 +$500;零環保罰款 +$200

## 本地管理及驗收介面（Streamlit）

```powershell
python -m pip install -r requirements-admin.txt
python -m streamlit run streamlit_app.py --server.address 127.0.0.1
```

介面讀取實際檔案及語法檢查結果，可匯入遊戲 `?qa=1` 匯出嘅 JSON。
Streamlit 需要 Python 伺服器，GitHub Pages 只提供靜態遊戲，唔會執行 Streamlit。

## 安全訓練室及入閘畫面

新入職：跟箭嘴報到 → 訓練室按 E → 五題課堂 → 同室健康檢查 → 領 PPE → 閘口按 E → 嘟卡。
訓練室係獨立 3D 互動場景，現時唔係自由行走室內。健康檢查屬遊戲節奏測試，唔係醫療量度。
失敗可休息 8 秒，返訓練室複檢，唔使重答已完成嘅五題。
入閘畫面使用實際地盤閘屋及當前狀態，缺少訓練、健康或 PPE 任一條件會停用嘟卡。
