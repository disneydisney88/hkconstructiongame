# ZCODE 補充規格：完整香港地盤運作

本文件係用戶新增要求，與人物上色及真實工地場景計劃一齊執行。不要把以下變成每步等待用戶批准嘅選單。記錄日期：2026-10-01。

## 1. 明確定位

遊戲要模擬一個有圍封、門禁、保安、安全部、管理層、分判商及多工種嘅香港施工地盤。背景佈局、人物行為及任務必須同一套施工邏輯，不能把施工設備隨機擺在普通城市道路旁。

法例、工作守則、項目規則及遊戲簡化設定須分層記錄。用戶提供2022年會議文件作具體項目參考，不自動代表2026年全港規定。法律符合性未經專業覆核前，不宣稱遊戲場景等同合規工程設計。

## 2. 入場流程：不能有先入場先訓練嘅矛盾

設置三層空間：公眾街道→受控接待／入職區→正式施工區。

### 首次到場

1. 到保安接待位置，核對角色身份、所屬分判、工種及適用資格；未登記角色不能穿過正式施工閘機。
2. 保安安排進入隔離嘅接待／入職區，或經指定安全通道由職員引領至安全部。該路線不穿過吊運、倒車或施工危險區。
3. 安全主任主持入職訓練：地盤範圍、PPE、人車分隔、吊運隔離、工作許可、事故呈報、緊急集合及工種風險。
4. 用簡短現場辨識／選擇題驗證理解；答錯針對項目重教，不要只做冗長文字測驗。
5. 安全部安排健康檢查位置及量血壓。健康評估需要轉介時，暫不授予施工區通行。
6. PPE、訓練、健康狀態及工作資格均滿足本項目入場規則後，發工作證／啟用模擬面容識別通行。
7. 玩家過閘後去所屬分判打理人／管工報到，再獲派當日工作。

### 往後到場

首日入職訓練記錄保留；按地盤要求安排重溫／再訓練，不每次過閘完整重讀。用戶要求每名工人量血壓，本遊戲採每日首次到場健康檢查作項目設定；未完成者先到檢查區。這個頻率不是宣稱全港統一法例。

通行可以用工作證打卡或角色站到模擬面容識別感應區；遊戲預設不存取玩家真實相機、不採集真人生物識別資料。讀取嘅係遊戲角色身份與權限。

### 必須有嘅身份狀態

未登記／接待區通行／訓練待完成／健康待評估／文件待核實／PPE未齊／可入施工區／限定工種權限／暫停入場／已離場。

閘機必須檢查狀態，顯示具體原因及下一步位置。不能只有開閘動畫而實際可從圍板旁繞入。保安、施工閘機與玩家任務使用同一份資料。

## 3. 血壓、健康與醫生文件

- 量血壓要有椅、桌、儀器及私隱相對合理嘅檢查位置；不是站喺馬路上撳反應遊戲。
- 以虛構角色健康數據驅動情境，不量測或診斷真人玩家。
- 異常結果→暫緩入施工區→按既定流程休息／複查／轉介；有不適時應求助。不要將快手撳掣設定成可以令異常血壓「合格」。
- 用戶要求保留「不合格暫不可入場，需醫生文件」情境。設計為取得相關醫療意見後，由地盤獲授權人員核實文件、工作限制及當日狀態，再更新通行權限，不是任何醫生紙都自動開閘。
- 安全主任負責組織流程，不扮演醫生作病症診斷。文件日期、角色身份及限制可以用虛構資料展示。
- 具體血壓閾值不要單靠2022年附件硬寫成醫學標準。若需要數字，以適用項目制度及醫療專業確認為前提，並標示係遊戲模擬。
- 不合格係健康安排，不記作安全違規、不罰健康不適者；可設計補文件、接受指示及復工流程。

## 4. 人員架構與分判關係

角色至少包括：保安、接待／安全部職員、安全主任、安全督導員、環保主任、工程師、總承建商管工、分判打理人、分判管工／工頭、機手、訊號員、工友、地盤經理、項目經理及公司管理層。

| 角色 | 遊戲中可見工作 |
|---|---|
| 保安 | 登記、核對入場狀態、閘口及車輛秩序 |
| 安全主任 | 入職訓練、巡查、要求停止危險工序、整改覆檢 |
| 安全督導員 | 工區持續巡查、即時提示、記錄及上報 |
| 環保主任 | 塵埃、污水、垃圾分類、化學品、泥車出閘檢查 |
| 工程師 | 圖則及施工安排協調、檢查／驗收；不能由NPC隨意批准真實結構設計 |
| 總承建商管工 | 工區與工種協調、工作面及通道安排 |
| 分判打理人 | 該分判人員、資格、物料、工期及違規跟進 |
| 分判管工／工頭 | 派工作、安排工友及設備、執行整改 |
| 機手／訊號員 | 按工作安排操作與協調吊運／機械活動 |
| 地盤經理 | 協調工序、資源、重要停工及復工 |
| 項目經理／公司管理層 | 項目交付、成本、重大管理決定及巡視 |

老總、PM、地盤經理不是必然同一職位；本虛構項目需給出清楚稱謂及分工。帽色採本項目規定，並以名牌、制服及行為辨識，不能只用帽色當普遍職責定義。

每個NPC有 companyId、trade、role、workZone、shift、任務及通行狀態。所有工友受相同門禁及危險區规则，不能只有玩家受管。

## 5. 人數與忙碌感

世界設定可以係數百至數千名在冊人員嘅項目，但不要把在冊人数冒充同屏實際模擬人数。

第一版建議先配置約150名虛構在冊人員，以測試結果決定近景詳細活動人数（例如20–40名作起始測試範圍）、中景簡化工組及遠景低細節活動。這是開發起始值，不係效能保證。

以班次、工區、人員來往及群組工作表現規模：閘口排隊、早會、領工具、搬料、綁筋、抹灰、機手工作、休息及收工。遠處角色簡化更新，但不能突然出現在危險範圍造成誤罰。玩家靠近時工作行為必須與已知狀態一致。

## 6. 工地邊界及施工階段

先畫平面佈局：圍封多邊形、行人閘、車閘、消防／緊急通道、接待區、辦公區、物料區、施工區、機械區、洗車區、廢料區。圍封可見模型與碰撞一致。

選定施工階段，不能同一位置同時挖地基、做完整室內裝修而無樓層／工區解釋。可設多座建築或不同樓層：A座上蓋結構、B座內裝、局部挖掘，分區說明清楚。

天秤要有服務中嘅未完工結構、基礎／支承及工作位置，起料區、落料區及吊运路線有用途。原有隨意放在已完工住宅旁嘅天秤要重新配置。附近存在已落成樓宇不自動代表不合理，重點係天秤服務邊項施工及配置是否有根據。

遊戲模型唔係施工圖；塔吊基礎、附着、承載、吊重表、淨空等工程參數不得憑AI想像宣稱合規。

## 7. 工種、設備及事件一齊設計

| 工種／區域 | 基本設備及場景 | 核心安全情境 |
|---|---|---|
| 泥水／抹灰／砌磚 | 砂漿、砌塊、推車、工作台 | 物料運送、通道、合適離地工作設備 |
| 油漆／裝修 | 油漆桶、工具、合適平台、通風及儲存位置 | PPE、化學品標籤、通風、動火活動相容性 |
| 竹棚／金屬棚 | 所選棚架系統、支承、連接、工作層、通道、圍護及檢查狀態 | 未驗收禁止使用、擅改部件、損坏報告 |
| 鋼筋／模板 | 鋼筋架、加工區、模板、支撑 | 堆料、吊運、臨邊及工種協調 |
| 挖掘 | 挖掘機、坑邊圍護、上落安排、機械隔離 | 人員進入回轉範圍、坑邊及地下設施相關風險 |
| 吊運 | 塔吊／移動式吊機、吊具、吊物、訊號員、隔離設施 | 未隔離、資格／檢查未齊、有人闖入吊運區 |
| 焊接／熱工序 | 適合設備、工作許可、消防安排、屏障 | 易燃物、許可未完成、設備缺陷 |
| 機電 | 配電及工具、電纜、通道 | 破損、積水、停用與交合適人員處理 |
| 環保及物流 | 洗車區、污水處理設施、篷布、分類料斗 | 泥車出閘、揚塵、污水及廢料 |

塔吊基礎周邊、吊運起落區、移動機械作業區都按各自情境設隔離，不以一個通用圓圈代替全部。隔離區隨任務狀態更新，警示、人員安排及動畫同步。

## 8. 梯具及棚架要求

梯具不能只判斷「低於2米即安全」。需根據工作種類、位置、設備適用性、狀況、穩定放置、通道及項目規則作判斷；適合用工作平台嘅工序應安排合適平台。2022年文件禁木梯及梯具檢验可作本項目設定，但不要寫成所有地盤同一規則。

竹棚與金屬棚不是貼圖互換。場景需對應選定系統嘅結構觀感、支承、通道、工作平台、圍護及檢查安排，並按適用工作守則核實。2026-07-31生效嘅兩份棚架守則增編要一併檢查；不得只沿用舊圖作合規結論。

## 9. 巡查及處理

安全主任／督導員按工區風險巡查，環保主任檢查環保項目。發現事件要有合理來源：視線、現場距離、工友通報或指定感測警報，不能隔牆全知。

事件流程：發現→指出具體問題→必要時叫停→記錄責任工組及依據→安排整改→覆檢→解除限制。緊急危險不必先等口頭警告才叫停；非緊急事項可按本項目程序給整改機會。

保留用戶要求嘅懲處情境，但分清工人警告／入場限制、分判商行政費及項目成本。處罰要有明確規則及對象，不把健康不適或主動報告事故當違規。重大／重複違規可通知分判打理人及地盤管理層處理，不能將安全主任簡化成GTA警察。

## 10. 自主驗收

1. 新工人未訓練，不能進施工區，但能沿安全路線去安全部。
2. 健康待評估時拒絕施工通行，提供清楚轉介／文件流程，不能翻牆繞入。
3. 文件核實及適用條件滿足後才恢復通行；普通NPC亦遵守。
4. 訓練記錄保存，第二次到場不無故重置。
5. 保安、閘機、安全部、工頭及工作任務狀態一致。
6. 工地四周有圍封，施工區與公眾道路分開。
7. 每架機械有合理施工用途，天秤與服務建築、物料起落區相配。
8. 每個工種有對應工具、工作動作及可見環境，至少六類在實際場景可辨認。
9. 棚架及梯具場景有來源依據與檢查狀態，不用外形相似代替合規。
10. 巡查能發現問題、叫停、整改及覆檢；不誤扣健康不適或正常路過者。
11. NPC數量、載入及動畫有實測效能報告；在冊人數與同屏角色數分開交代。
12. 完整錄製：保安登記→訓練→健康檢查→過閘→分判報到→工種任務→巡查事件→整改→交付。另測一次健康不合格及恢復通行流程。
